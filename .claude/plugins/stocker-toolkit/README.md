# stocker-toolkit

Project-specific skills for the Stocker Flask stock analysis app.

## Skills

- **stocker-deploy** — Pre-flight checklist, deploy command, post-deploy verification, rollback, common failures
- **stocker-cache** — Cache layer map, bumping rule versions, force-refresh, per-symbol cache deletion, quota interaction
- **stocker-debug** — Triage by symptom: predict errors, quota bugs, OAuth, Stripe webhooks, AI features, Fly.io logs

## Activation

Skills activate automatically based on context. You can also invoke them explicitly:
- `/stocker-deploy`
- `/stocker-cache`
- `/stocker-debug`
